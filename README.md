# UniLoop — Campus Marketplace

UniLoop is a student-focused campus marketplace that enables students to buy, sell, donate, exchange, and request items within their college community.

## Features

- **User Authentication** — Secure registration and login with college email validation.
- **Item Listings** — Create, edit, and manage marketplace listings.
- **Request Management** — Send, accept, reject, and cancel item requests.
- **Handover Chat** — Enables communication between buyers and sellers for accepted requests.
- **User Profiles** — Manage account details and view personal activity.
- **Admin Dashboard** — Manage and monitor marketplace activities.

## Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf
- **Database:** MySQL
- **Build Tool:** Maven
- **Security:** Spring Security Crypto (BCrypt password hashing)

## Getting Started

### Prerequisites

- Java JDK 21
- Maven
- MySQL Server
- Git

### Installation

1. Clone the repository.
2. Configure your MySQL database credentials.
3. Run `mvn spring-boot:run`.
4. Open `http://localhost:8080` in your browser.
